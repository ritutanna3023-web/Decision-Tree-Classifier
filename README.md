# Decision Tree Classifier - Purchase Prediction

## About the Project

This is a beginner-friendly Machine Learning project that uses a Decision Tree Classifier to predict whether a customer may purchase a product based on age and income.

## Algorithm Used

* Decision Tree Classifier
* Gini Impurity

## Technologies and Libraries

* Python
* Pandas
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Dataset

The project uses a small sample dataset with the following features:

* Age: Customer's age
* Income: Customer's income
* Buy: Purchase outcome (0 = No, 1 = Yes)

## Project Workflow

1. Import required libraries.
2. Create a sample dataset.
3. Separate input features and target.
4. Split data into training and testing sets.
5. Train the Decision Tree model.
6. Visualize the decision tree.
7. Evaluate model performance.
8. Predict purchase behavior for a new customer.

## How to Run

Install the required libraries:

```bash
pip install pandas matplotlib scikit-learn jupyter
```

Open the notebook using Jupyter Notebook and run all cells.

## Learning Outcomes

* Understanding Decision Tree Classification
* Training a classification model
* Visualizing a decision tree
* Evaluating model performance
* Making predictions for new inputs

## Note

This project uses a very small sample dataset for educational purposes. It is not intended for real-world purchase predictions.
